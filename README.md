# 🧠 AI Interview Preparation Portal

A  web application that helps users prepare for technical interviews with AI-generated MCQs and personalized feedback. Includes admin, user roles, JWT authentication.

---

## 📌 Features

### 🧑‍💻 User
- 🔐 Register & login with JWT-based authentication
- 🎯 Select topics (e.g., Java, C, DSA)
- ❓ Get AI-generated interview questions (MCQs or subjective)
- 📝 Submit answers and receive AI-powered feedback
- 📄 Upload your resume and get an AI-based review and suggestions

### 👨‍💼 Admin
- 👥 View/manage registered users

---

## ⚙️ Tech Stack

| Layer        | Tech/Tool                  |
|--------------|----------------------------|
| Backend      | Spring Boot (Java)         |
| Database     | MongoDB                    |
| Auth         | JWT (Spring Security)      |
| AI Services  | OpenRouter / HuggingFace APIs |
| Build Tool   | Maven                      |
